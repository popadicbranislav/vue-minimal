# Minimal Vue - Vue 3 starter template with TypeScript and Vite

This is a simple starter template to kickstart your Vue 3 project with TypeScript and Vite.

## Features

- [Vite](https://vite.dev/) - Next Generation Frontend Tooling.
- [Vue Router](https://router.vuejs.org/) - The official router for Vue.js.
- [Tailwind CSS](https://tailwindcss.com/) - A utility-first CSS framework.
- [Vitest](https://vitest.dev/) - A blazing fast unit test framework.
- [Iconify](https://iconify.design/) - Universal icon framework.
- [vite-plugin-pages](https://github.com/hannoeru/vite-plugin-pages) - File system based routing for Vite.
- [unplugin-auto-import](https://github.com/unplugin/unplugin-auto-import) - Auto import APIs on-demand for Vite.

## Getting Started

```bash
npx degit git@github.com:popadicbranislav/vue-minimal.git my-vue-app
```

After cloning the repository, navigate to the project directory and install the dependencies:

```bash
cd my-vue-app
pnpm install
```

Happy coding! 🚀
